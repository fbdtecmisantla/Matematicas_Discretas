4.3.2 Representación de expresiones booleanas con circuitos lógicos

Una expresión booleana puede representarse gráficamente mediante un circuito lógico, utilizando compuertas que realizan operaciones lógicas sobre variables de entrada para obtener una salida.

Las compuertas lógicas básicas son AND, OR y NOT. Cada una representa una operación del álgebra booleana y tiene un símbolo específico en los diagramas de circuitos digitales.

2. ¿Cómo representar una expresión booleana con un circuito?
Para construir el circuito, se deben seguir estos pasos:

Identificar las variables de entrada de la expresión.
Identificar las operaciones lógicas que aparecen.
Colocar las compuertas correspondientes a cada operación.
Conectar las salidas de las compuertas según el orden de las operaciones.
Obtener la salida final y comprobar su funcionamiento mediante una tabla de verdad.
